# Conceptos que se practican

## HTML
- Formularios (`<form>`, `<input>`, `<label>`, `<button>`)
- Etiqueta `<audio>` para reproducir música
- `<input type="range">` como barra de progreso
- Íconos con `<svg>`

## CSS
- Variables (`--tinta`, `--crema`, ...)
- Flexbox (`display: flex`) y Grid (`display: grid`)
- Diseño adaptable con `@media` (celular y computadora)
- `clamp()` para textos que crecen con la pantalla

## JavaScript
- Arreglos de objetos (`canciones`)
- Funciones
- Condicionales `if / else`
- Ciclo `for`
- Seleccionar elementos: `document.getElementById`
- Eventos: `click`, `submit`, `input`
- Eventos del audio: `timeupdate`, `loadedmetadata`, `ended`
- Mostrar/ocultar con `classList.add` y `classList.remove`
- Convertir segundos a minutos (`Math.floor` y `%`)
