# Notas para asistentes de IA

Proyecto de uni: reproductor de música en HTML, CSS y JavaScript **sin librerías**.

## Reglas
- Mantener el código **simple y fácil de leer** para principiantes.
- Usar `function` normales, `for`, `if/else`, `getElementById` y `addEventListener`.
- Evitar clases, frameworks, módulos, `async/await` y trucos avanzados.
- Nombres de variables y comentarios **en español**.
- Seguir los colores y estilo de `Design.md`.
- Las canciones solo se agregan en el arreglo `canciones` de `app.js`.

## Datos
- Login: usuario `usuario`, contraseña `1234`.
- Audios en `canciones/`, portadas en `portadas/`.
